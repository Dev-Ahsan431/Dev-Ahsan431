## Experience Highlights

**WordPress and PHP**

Most of my experience is in building custom WordPress solutions well beyond themes and plugins. I work with custom post types, taxonomies, shortcodes, admin dashboards, hooks, filters, custom data models, WooCommerce flows, and full plugin architecture. I take a business requirement and turn it into a working WordPress feature, plugin, integration, or automated workflow.

**WooCommerce and Ecommerce**

I've built custom ecommerce logic including multi-vendor order segmentation, role-based dashboards, subscription lifecycle management (activation, expiry, content gating), custom payment flows, Stripe-based vendor payout systems, and custom checkout behavior.

**APIs and Integrations**

I build and connect APIs for real-world systems — REST APIs, webhook processing, external services, payment providers, and custom backend communication. Projects have involved AWS (SES, SQS, Rekognition), Firebase (social auth), Telnyx (OTP), Veriff (KYC), EasyPost (shipping), Centrifugo (real-time messaging), and Stripe (payments and payouts).

AI is a growing and serious part of my work across four areas.

*AI-assisted development* — I use GitHub Copilot, Cursor, Claude, and Gemini as daily tools in my workflow. Not as a shortcut, but as a force multiplier for accelerating feature delivery, debugging complex issues, and prototyping faster. This has cut development time by an estimated 30–40% on routine tasks.

*AI API integrations* — I integrate AI APIs (OpenAI, Gemini, Claude) directly into web applications and WordPress plugins, enabling features like content generation, intelligent search, automated categorization, and conversational interfaces embedded inside client products.

*AI-powered tools and products* — I build standalone tools and product features driven by AI. ToolBox ([tools.inferexcore.com](https://tools.inferexcore.com)) is one example — a growing open-source utility suite where AI-driven features are part of the roadmap.

*AI automation and workflows* — I design and implement automated pipelines that use AI for processing, decision-making, and triggering actions — reducing manual work in client systems and internal tools.
